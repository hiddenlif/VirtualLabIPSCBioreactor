# Interface assets

- Icons: Feather v4.29.2, MIT license. Source: https://github.com/feathericons/feather/tree/v4.29.2/icons . The original license is retained in `icons/LICENSE`.
- Typography: Georgia with Times New Roman fallback for display text; system sans-serif and monospace for controls and evidence labels. No remote font request.
- `reactor-v2.png`: AI-generated illustrative reactor, created for this project from the approved design direction. It depicts neither measured geometry nor an experimentally observed culture. Its canvas animation only displaces illustration pixels; the scientific simulator does not consume them.
