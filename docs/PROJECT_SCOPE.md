# Project scope

Updated 2026-10-26 08:44 PDT.

This repository contains the completed first iPSC expansion-and-banking research simulator: source, local interface, tests, executed synthetic evaluation, source audit and reproducibility evidence. Its scientific limitations and retained QC failures remain documented.

The spatial tumor laboratory has its own repository, [VirtualLabSpatialTumor](https://github.com/hiddenlif/VirtualLabSpatialTumor). Later scientific and product updates build on this release.

Local runtime sessions and the original private pilot working states are excluded from Git. The public pilot traces and unmasked closeout design needed to reproduce the reported study are included. Frozen scientific source files and study results are unchanged by repository preparation.
